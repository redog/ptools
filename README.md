ptools by redog

Promptware rebuild of 2004 portage tools. Written originally while I was learning python ~ 2004-2005

This project intends to rebuild some of those tools with modern changes in mind and better integration with gentoo's established tools.

Coding will be mostly handled by jules.google.com with me managing the vibes as the kids call it.
